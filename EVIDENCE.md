# Evidence Ledger

This file is a reviewer-facing map of the claims made by the resume. It separates public evidence from reference-check evidence so the repo can be candid without over-publishing client or employer material.

## How to read this

- Public source: A URL a reviewer can inspect without asking Sam for context.
- Reference path: A person, artifact class, or private record Sam can offer during a serious hiring process.
- Confidence: How directly the public source supports the claim.
- Caveat: Limits on what can be published because of client confidentiality, employment context, or NDA boundaries.
